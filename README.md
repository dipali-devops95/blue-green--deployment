# Blue-Green Deployment on AWS

**Project Platform:** KodeKloud

## Project Overview
Hands-on practice in AWS infrastructure configuration and Blue-Green Deployment using EC2 instances, Application Load Balancer, and target groups.
## Tools and Technologies
- Amazon VPC
- Public Subnets
- Internet Gateway
- Route Tables
- EC2 Instances
- Security Groups
- Target Groups
- Application Load Balancer (ALB)
- AWS User Data
- KodeKloud

## Key Tasks
- Created a custom VPC with two public subnets across different Availability Zones.
- Configured an Internet Gateway and route table.
- Prepared Blue and Green application versions using EC2 instances.
- Configured separate target groups for Blue and Green environments.
- Practiced switching traffic using an Application Load Balancer.
- Reviewed the rollback process to return to the previous version.
